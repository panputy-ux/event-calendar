# イベントカレンダー v1（GitHub Pages用）

## 今回の機能
- 画像を参考にしたダークテーマの月間カレンダー
- 前月・翌月・今日・年月指定
- 単日イベント・複数日イベントを表示（週や月をまたぐ期間にも対応）
- 親イベントで絞り込み
- カレンダーの子イベントを押すと詳細ポップアップ
- 月間一覧の親イベントを押すと説明文と子イベント一覧のポップアップ
- レスポンシブ対応（スマホ・PC）

## 初回アップロード
1. GitHubの `event-calendar` リポジトリを開きます。
2. `Add file` → `Upload files` を開き、このフォルダ内の `index.html`, `style.css`, `calendar.js`, `sample-events.js` をまとめてドラッグします。
3. 既存の `index.html` は上書き対象になります。同名ファイルがある場合、GitHubの画面に従って差分を確認してください。
4. `Commit changes` を押します。`main` ブランチのルートに4ファイルが並んでいればOKです。
5. 数分後に GitHub Pages のサイトを再読み込みします。

## 今後の変更
- 今は `sample-events.js` の仮データを表示します。すべてサンプルとして表示しています。
- Googleスプレッドシート連携時にデータ取得処理を置き換えます。
- GAS側で親イベント・子イベントの登録／編集／削除フォームを作ります。

## データ形式（将来のスプレッドシート用）

親イベント：`id`, `name`, `description`, `color`

子イベント：`id`, `parentId`, `title`, `startDate`, `endDate`, `startTime`（任意）, `endTime`（任意）, `description`（任意）

日付は `YYYY-MM-DD`、時刻は `HH:mm`（任意）です。

## 注意事項
- 現段階ではWebサイト上からデータを書き換えることはできません。
- Googleスプレッドシートへの接続・閲覧権限の設定は次工程です。
- サンプルデータを実データと混同しないよう、名前に（サンプル）を付けています。
- 外部リンクは仕様に従い搭載していません。
